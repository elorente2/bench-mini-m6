# Fairness rules

These rules are part of the benchmark, not suggestions. A result that violates
them is not comparable and should be marked invalid or rerun.

1. **One model-loaded engine at a time.** A 32 GB machine cannot hold two 27B
   engines. Stop Splash before Mirai and vice versa.
2. **Verify the listener.** Exactly one process may listen on the engine port.
   The harness aborts otherwise.
3. **An idle Ollama service is allowed, a loaded Ollama model is not.** Before a
   Splash or Mirai pass, `ollama ps` must be empty.
4. **Same suite revision.** All contenders in one comparison must use the same
   `[suite].revision`, prompts and output token limits.
5. **Temperature 0.** Requests use `temperature: 0`. A fixed seed is sent when
   the engine accepts it.
6. **Reasoning disabled equivalently.** Splash uses `reasoning_effort: none`,
   Mirai uses `disabled`, and Ollama omits the field. Reasoning tokens are
   counted separately if an engine emits them.
7. **Same prompt bytes.** The long prefix is deterministic and generated by the
   repository. Do not edit it between contenders.
8. **Warmup is discarded.** One short request loads kernels and opens sockets;
   it is never recorded.
9. **Cold and cached are separate.** Never present a cache hit as a cold
   prefill, or a reprefill as a cache hit.
10. **Cached runs must validate.** A cache case is valid only if prompt tokens
    are not lost and cached TTFT is substantially lower than cold TTFT. Invalid
    cases are excluded, not averaged.
11. **Repeated runs use the median.** Short decode runs at least three times.
12. **No downloads, model conversions or heavy apps during a pass.** They
    change memory pressure and throughput.
13. **Record the environment.** Engine version, model identifier,
    quantization, suite revision, macOS, chip and memory go into every result.
14. **Do not edit historical results.** Add a new dated JSON file and a new
    report instead.
15. **Different weights mean speed only.** State clearly that a Q3_K_XL GGUF
    versus a 4-bit M model is not a quality comparison.
16. **Do not stop services without consent.** The harness may stop engines it
    started; stopping a user-managed service requires an explicit `--force`.

## Reporting an invalid case

```json
"validation": {
  "cached_ttft_long": {
    "valid": false,
    "reasons": [
      "cached TTFT (34975 ms) is not meaningfully lower than cold TTFT (34072 ms)"
    ]
  }
}
```

The report shows the case under **Validity** and leaves the metric blank. The
raw value remains in `summary.reported_cached_ttft_long_ms` for transparency.
